## templates/
- `quiz_tpl.html` + `make_quiz.py` — генератор викторины из файла урока (`data/units/unitNN.js`): `python3 make_quiz.py unit10.js`. Пути внутри скрипта абсолютные, из старой среды; поправь при переносе.
- `tpl_cards.html`, `tpl_panel.html`, `build_cards.py` — исходники карточек и панели (данные подставляются вместо `__DATA__`, `__API__`, `__DECK__`).
- `mock_gas.js` + `e2e.py` — имитация Google Apps Script на Node и сквозной тест Playwright, которыми проверялась текущая версия. Пригодятся как образец сценариев для новых e2e-тестов.

## Данные: где лежат в `data/`
- `data/decks/w100.json`, `w100b.json` — наборы карточек: `[[тема, [[арабский, русский], …]], …]`.
- `data/dictionary_thematic.json` — тематический словарь (557 слов, 16 тем).
- `data/units/unitNN.js` — исходники уроков (текст, вопросы, множественные, антонимы, пропуски, ошибки); `Matn_NN_quiz.json` — то же в JSON.
- `data/from_pages/*.json` — массивы данных, извлечённые из каждой HTML-страницы (`POOL`, `PARA`, `LIS`, `PAIRS` …), в том виде, как их использует прототип.
