# Unmuzaj · الأُنْمُوذَجُ

Сайт арабского языка: https://otabekikrombek.github.io/unmuzaj/

*Barcha arab tili ixlosmandlari uchun.* Автор — Отабек Икромбеков.

## Для автора: как это устроено

- **Сайт** собирается автоматически: после каждого изменения в репозитории GitHub за 1–2 минуты публикует новую версию (вкладка **Actions** → «Публикация сайта»).
- **База данных** — Supabase (проект `unmuzaj`, Франкфурт). Там хранятся классы, ученики и прогресс. Схема — в файлах `supabase/migrations/0001_init.sql`, `0002_quizzes.sql` (выполняются по порядку в Supabase → SQL Editor).
- **Учебные материалы** лежат в `src/content/`, по одному файлу JSON на материал. Добавили файл — после публикации он появился на сайте. Форматы описаны в `src/content/SCHEMA.md`.
- Контакты, девиз и название меняются в одном файле: `src/config/site.ts`.

## Викторины

- **Новая викторина по уроку:** положите файл урока в `data/units/` (например, `unit11.js`) и попросите Claude: «сделай викторину по unit11» — он выполнит `npm run make-quiz -- unit11`, проверит и опубликует.
- **Табло для проектора:** Панель учителя → «Викторины» → выберите викторину → «Табло для проектора». Откроется большая таблица с псевдонимами, она обновляется каждые 5 секунд. Адрес вида `…/board/matn-10/?class=КОД`.
- **Результаты:** Панель учителя → «Викторины»: кто прошёл, лучшие результаты, части, трудные вопросы, разбор каждой попытки, выгрузка всех ответов в CSV.
- Ученики без входа (гости) тоже могут проходить викторины, но их результаты не сохраняются в базе и не попадают в рейтинг.

## Спряжение глаголов

- Раздел **«Спряжение»** (меню «Учить»): таблицы ~100 частых глаголов и режим «Любой глагол». Таблицы строит программа Qutrub (© Taha Zerrouki, GPL); огласовка настоящего времени и переходность взяты из словаря Arramooz.
- Пока таблицы не проверены, на каждой странице написано «Формы ещё не проверены преподавателем». Список глаголов — файл `src/data/verbs.json`. Проверили глагол — попросите Claude: «отметь كَتَبَ как проверенный» (он поставит `"checked": true`). Нашли ошибку — напишите Claude, какая форма неверна.
- Добавить глагол: попросите Claude «добавь в спряжение глагол …» — он возьмёт огласовку из словаря, пересоберёт таблицы (`npm run conjugate`) и опубликует.

## Оформление и поиск

- **«Aa» в шапке** — меню «Оформление»: светлая, тёмная или «как в системе»; четыре набора цветов (Бирюза, Лазурит, Пергамент, Контраст); размер текста и отдельно размер арабского шрифта. Выбор запоминается на устройстве.
- **Лупа в шапке** (или клавиши `/` и `Ctrl+K`) — поиск по всему сайту: слова из словаря и наборов, задания, разделы. Ищет по-русски и по-арабски, с огласовками и без. Новые материалы попадают в поиск сами при публикации.
- Все цвета сайта — в одном файле `src/styles/tokens.css`. Меню сайта — в `src/config/nav.ts`.

## Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Ученики не могут войти, «Нет связи с сервером» | Возможно, база «уснула». Откройте supabase.com → проект `unmuzaj` → **Restore project**. Обычно этого не бывает: раз в 3 дня её будит автоматическая задача («Будильник базы данных» во вкладке Actions). |
| Ученик забыл ПИН | Панель учителя → «Ученики и ПИН» → отметьте ученика → «Новый ПИН отмеченным». |
| Ученик прошёл викторину без интернета | Результат хранится на его телефоне и отправится сам, когда появится связь и он снова откроет сайт. |
| Вы забыли пароль учителя | Supabase → Authentication → Users → ваш email → Send password recovery. |
| Нужно добавить другого учителя | Supabase → Authentication → Users → Add user, затем на сайте: Панель учителя → «Администратор» → email → «учитель». |

## Переход на собственный домен (позже)

1. Купить домен (например, `unmuzaj.uz`) и в его настройках DNS добавить записи для GitHub Pages: 4 записи `A` на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
2. Попросить Claude: «переведи сайт на домен unmuzaj.uz». Он добавит файл `public/CNAME` и поменяет `SITE`/`BASE` в `astro.config.mjs`. Ссылки внутри сайта поправятся сами.
3. GitHub → Settings → Pages → Custom domain → ввести домен → Enforce HTTPS.
4. Supabase → Authentication → URL Configuration: заменить адрес сайта на новый.
