# Форматы учебных материалов

Один материал — один файл JSON в нужной папке. Имя файла совпадает с полем `key` (латиницей, через дефис). Общие поля для всех типов:

| Поле | Что это | Пример |
|---|---|---|
| `key` | адрес материала на сайте | `"w100"` → `/words/w100/` |
| `title` | название | `"100 слов недели"` |
| `description` | 1–2 предложения: для списка и для поиска Google | |
| `level` | уровень | `"A1"` |
| `topics` | темы | `["семья", "дом"]` |
| `added` | дата добавления, ГГГГ-ММ-ДД | `"2026-10-12"` — по ней строится «Новое на сайте» |
| `courses` | в какие курсы входит | `["tsu-2-sem1"]` |

## `decks/` — наборы слов

```json
{ "key": "w100", "title": "…", "description": "…", "level": "A1", "topics": ["Семья"], "added": "2026-10-10", "courses": ["tsu-2-sem1"],
  "items": [ { "a": "أَبٌ – آبَاءٌ", "r": "отец", "t": "Семья" },
             { "a": "كَبِيرٌ ≠ صَغِيرٌ", "r": "большой ≠ маленький", "t": "Прилагательные — пары" } ] }
```

- `a` — арабский с огласовками, единственное – множественное через « – ».
- Прилагательные даются парой через « ≠ ».
- `r` — перевод.
- `t` — тема внутри набора (по ней работает фильтр).

**Важно:** прогресс учеников привязан к арабскому написанию слова (`a`). Если исправить опечатку в `a`, прогресс по этому слову начнётся заново.

## `quizzes/` — викторины и тесты

`kind`: `"quiz"` — викторина (раздел «Викторины»), `"test"` — тест (раздел «Тесты»), `"mock"` — пробный экзамен с общим таймером (раздел «Пробные экзамены», см. ниже).

**Викторину по уроку не нужно писать руками:** `npm run make-quiz -- unit11` соберёт её из файла урока `data/units/unit11.js` (как раньше `make_quiz.py`). Потом проверьте название и темы.

```json
{ "key": "matn-10", "title": "Урок 10: «Друг и семья»", "description": "…", "level": "A1", "topics": ["текст"],
  "added": "2026-10-11", "kind": "quiz", "courses": ["tsu-2-sem1"],
  "plan": [["F", 8], ["V", 4], ["G", 5], ["E", 3]],
  "sections": { "F": { "ar": "فَهْمُ النَّصِّ", "ru": "понимание", "icon": "📖", "sec": 30 }, "…": {} },
  "ins": { "F": { "ar": "اِقْرَأِ النَّصَّ، ثُمَّ أَجِبْ عَنِ الْأَسْئِلَةِ.", "ru": "Текст открывается кнопкой «📄 Текст»…" } },
  "title_ar": "صَدِيقِي مِنْ مِصْرَ",
  "para": [ { "label": "الْمُقَدِّمَةُ", "sentences": ["…", "…"] } ],
  "levels": [ { "min": 19, "label": "Мастер 🏆" }, { "min": 16, "label": "Отлично 🌟" }, { "min": 0, "label": "Начинающий 🌱" } ],
  "pool": [ { "id": 1, "s": "F", "q": "مَا عُنْوَانُ النَّصِّ؟", "o": ["صَدِيقِي مِنْ مِصْرَ", "أُسْرَتِي", "مَدِينَتُنَا", "جَامِعَتُنَا"], "e": "Заголовок текста." } ] }
```

| Поле | Что это |
|---|---|
| `plan` | части по порядку и сколько вопросов взять из каждой. Каждый ученик получает свой случайный набор. |
| `sections` | части: `ar` — название по-арабски (необязательно), `ru` — по-русски, `icon` — значок, `sec` — секунд на вопрос |
| `ins` | инструкция перед частью (необязательно). Если частей одна и инструкции нет — вопросы начинаются сразу. |
| `text_in` | в каких частях доступна кнопка «📄 Текст» (необязательно; по умолчанию — во всех, если есть `para`) |
| `para` | текст урока по абзацам (необязательно) |
| `lis` | диалог для аудирования, часть `L`: `[{"who": "أ", "text": "…"}]`. Читается голосом устройства, не больше двух раз. |
| `audio` | (необязательно) файл записи диалога в `public/`, например `"audio/istima_mock1.mp3"` — тогда звучит запись |
| `levels` | уровни по числу верных ответов: `min` — от скольких верных |
| `pool` | вопросы: `id` — номер (не менять после публикации!), `s` — часть, `q` — вопрос, `o` — варианты, **первый — правильный** (на экране они перемешиваются), `e` — пояснение «почему» |

**Важно:** по `id` вопроса учитель видит статистику «трудных вопросов». Если вопрос исправлен — оставьте `id`; если заменён на совсем другой — дайте новый `id`.

При сборке сайт сам проверит: нет повторяющихся `id`, у каждой части хватает вопросов для плана, у вопроса нет одинаковых вариантов.

### Пробный экзамен (`"kind": "mock"`)

Файл лежит там же, в `quizzes/`, но страница — в разделе «Пробные экзамены»: `/mock/<key>/`. Это экзамен, а не викторина: один общий таймер на всё время, вопросы можно листать и менять ответ, нет очков, уровней, звуков и подсказок «верно/неверно». Результат — после сдачи: число верных, разбор и сводка по темам.

```json
{ "key": "tanal-nahw", "title": "…", "description": "…", "level": "B1", "topics": ["экзамен"], "added": "2026-10-16",
  "kind": "mock", "duration_min": 30, "max_exits": null, "title_ar": "اِخْتِبَارٌ تَجْرِيبِيٌّ فِي النَّحْوِ",
  "plan": [["G", 30]],
  "sections": { "G": { "ar": "النَّحْوُ", "ru": "грамматика (нахв)", "icon": "🧩", "sec": 60 } },
  "topic_names": { "1": "أَقْسَامُ الْكَلِمَةِ", "2": "نَصْبُ الْفِعْلِ الْمُضَارِعِ" },
  "pool": [ { "id": 1, "s": "G", "topic": 1, "q": "…", "o": ["правильный", "…", "…", "…"], "e": "Тема — …" } ] }
```

| Поле | Что это |
|---|---|
| `duration_min` | минут на **весь** экзамен (обязательно). В 0:00 экзамен сдаётся автоматически. |
| `max_exits` | сколько выходов из окна экзамена допускается; при превышении экзамен сдаётся автоматически. `null` — не ограничено (выходы только считаются). |
| `plan` | сколько вопросов взять (из всех частей вместе — вопросы перемешиваются) |
| `topic_names` | названия тем по номеру (по-арабски, не переводятся) — для сводки «по темам» |
| `pool[].topic` | номер темы вопроса (у At-Tanāl — номер мабхаса). Обязательно у каждого вопроса. |
| `pool[].o` | 2–4 варианта, **первый — правильный**; на экране они перемешиваются и подписываются أ ب ج د |

`levels`, `ins` и `sec` в частях у пробного экзамена не используются (их можно не писать). Номер `id` вопроса после публикации не менять — так же, как у викторин.

## `exercises/` — упражнения

Как викторины, пока через `legacy`.

## `courses/` — курсы

```json
{ "key": "tsu-2-sem1", "title": "…", "description": "…", "audience": "…", "added": "2026-10-12",
  "items": [ { "kind": "deck", "key": "w100" }, { "kind": "quiz", "key": "matn-10", "note": "после урока 10" } ] }
```

`kind`: `deck`, `quiz`, `test`, `mock`, `exercise` (позже `grammar`, `text`). Порядок в `items` — порядок прохождения.

## Переводы на узбекский и английский (необязательно)

Сайт открывается на трёх языках: русский — `/…`, узбекский — `/uz/…`, английский — `/en/…`. Интерфейс (кнопки, меню, подсказки) уже переведён. **Учебные материалы пишутся по-русски**, а переводы добавляются рядом — в необязательные поля с окончанием `_uz` (узбекский, латиница) или `_en` (английский). Арабский текст не переводится.

Если перевода нет, на узбекской и английской версиях показывается русский текст с пометкой «(rus tilida)» / «(in Russian)». Поэтому переводить можно постепенно: по одному слову или вопросу.

| Где | Русское поле | Перевод | Пример |
|---|---|---|---|
| любой материал | `title`, `description` | `title_uz`, `description_uz` (`title_en`…) | `"title_uz": "Haftaning 100 ta soʻzi"` |
| слово в наборе (`decks/`) | `r` | **`r_uz`**, `r_en` | `{ "a": "أَبٌ – آبَاءٌ", "r": "отец", "r_uz": "ota", "t": "Семья" }` |
| вопрос викторины (`pool`) | `q` — вопрос | `q_uz`, `q_en` | только если в вопросе есть русский текст |
| | `o` — варианты | `o_uz`, `o_en` | столько же вариантов и **в том же порядке** (первый — правильный); только если варианты русские |
| | `e` — пояснение | **`e_uz`**, `e_en` | `"e": "Заголовок текста.", "e_uz": "Matn sarlavhasi."` |
| часть викторины (`sections`) | `ru` | `uz`, `en` | `"F": { "ar": "فَهْمُ النَّصِّ", "ru": "понимание", "uz": "matnni tushunish", … }` |
| инструкция (`ins`) | `ru` | `uz`, `en` | |
| уровень (`levels`) | `label` | `label_uz`, `label_en` | `{ "min": 16, "label": "Отлично 🌟", "label_uz": "Aʼlo 🌟" }` |
| курс (`courses/`) | `audience` | `audience_uz`, `audience_en` | |
| глагол в разделе «Спряжение» (`src/data/verbs.json`) | `ru` | `uz`, `en` | `{ "verb": "كَتَبَ", "ru": "писать", "uz": "yozmoq", … }` |

Правила:
- Узбекский — официальная латиница: oʻ, gʻ пишутся со знаком **ʻ** (U+02BB), тутуқ белгиси — **ʼ** (U+02BC): `soʻz`, `maʼlumot`. Обычный апостроф `'` не ставить.
- Термины грамматики — как в глоссарии `src/i18n/glossary.json` (ot, sifat, izofa, kishilik olmoshi…).
- Поле `a` (арабский) и тема `t` не переводятся и не меняются: по ним хранится прогресс учеников.
- При сборке сайт проверит, что в `o_uz` / `o_en` столько же вариантов, сколько в `o`, и они не повторяются.
## Спряжение глаголов — `src/data/verbs.json` и `conjugations/`

Список глаголов раздела «Спряжение» — `src/data/verbs.json` (массив). Таблицы спряжения строит программа **Qutrub**: после правки списка выполните `npm run conjugate` — она создаст или обновит файлы `src/content/conjugations/<key>.json`. **Таблицы руками не правят**: при следующем запуске они перезапишутся. Если `verbs.json` изменён, а таблицы не пересобраны, сборка сайта остановится с подсказкой.

```json
{ "key": "kataba", "verb": "كَتَبَ", "root": "كتب", "future_type": "ضمة", "transitive": true, "ru": "писать",
  "source": { "list": "freq", "freq": 50, "bab": "arramooz+task", "transitive": "arramooz", "ru": "claude" },
  "doubt": false, "checked": false }
```

| Поле | Что это |
|---|---|
| `key` | адрес страницы: `/conjugation/kataba/` (латиницей; после публикации не менять) |
| `verb` | глагол в прошедшем времени, 3-е л. ед. ч. м. р., **с огласовками** |
| `root` | корень (хамза — `ء`); по нему определяется тип: правильный, хамзованный, подобный правильному, пустой, недостаточный, удвоенный, дважды слабый |
| `future_type` | огласовка второго корневого в настоящем-будущем: `"فتحة"` (يَفْعَلُ), `"ضمة"` (يَفْعُلُ), `"كسرة"` (يَفْعِلُ) |
| `transitive` | `true` — переходный (полный страдательный залог), `false` — непереходный (только безличная форма) |
| `ru` | перевод |
| `source` | откуда данные: `list` — почему глагол в списке (`freq` — частотный словарь Arramooz, `freq` — его номер среди глаголов I породы; `task` — задание заказчика; `dictionary` — словарь сайта); `bab` и `transitive` — источник огласовки и переходности (`arramooz` — словарь Arramooz, `qutrub` — таблица глаголов Qutrub, `+task` — подтверждено заданием, `teacher` — преподаватель); `ru` — кто перевёл (`claude` — не проверено) |
| `doubt` | `true` — данные сомнительны (в словаре несколько вариантов, словари расходятся или глагола нет в Arramooz) |
| `doubt_note` | что именно сомнительно и какой вариант выбран (видно на странице глагола под «Для преподавателя») |
| `checked` | `true` — преподаватель проверил таблицу. Пока `false`, на странице написано «Формы ещё не проверены преподавателем» |

**Как добавить глагол.** Узнать огласовку и переходность по словарям: `npm run conjugate:lookup -- كتب` (Arramooz и таблица Qutrub). Добавить запись в `verbs.json`, выполнить `npm run conjugate`, закоммитить оба изменения. Проверить весь список по словарю: `npm run conjugate:lookup`.

**Как отметить проверку.** Преподаватель проверил таблицу → `"checked": true` (и, если всё верно, `"doubt": false`). Нашлась ошибка в огласовке или переходности → исправить `future_type` / `transitive`, в `source` указать `"teacher"`, выполнить `npm run conjugate`. Если ошибается сам Qutrub (неверная форма при верных данных), таблицу не правят: ошибку записывают в описание и решают отдельно.
