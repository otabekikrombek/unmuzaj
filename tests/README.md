# Тесты

## База данных (`supabase/tests/`)

Нужен локальный PostgreSQL 15+ (проверено на 17).

```bash
createdb t1
psql -d t1 -f supabase/tests/00_supabase_stub.sql      # имитация auth.users, auth.uid(), ролей anon/authenticated
psql -d t1 -c "insert into auth.users(email, created_at) values ('teacher@x', now() - interval '1 day'), ('other@x', now())"
psql -d t1 -v ON_ERROR_STOP=1 -f supabase/migrations/0001_init.sql
psql -d t1 -v ON_ERROR_STOP=1 -f supabase/migrations/0002_quizzes.sql
psql -d t1 -f supabase/tests/10_test.sql
psql -d t1 -f supabase/tests/20_quiz_test.sql   # викторины; в конце печатает «quiz tests passed»
```

Что проверяется:
- вход по ПИН и неверный ПИН;
- блокировка после 5 ошибок;
- синхронизация без дублей;
- устаревшие данные не затирают новые;
- нет прямого доступа к таблицам;
- чужой учитель ничего не видит;
- отчёт, сброс ПИН, роли;
- викторины: сохранение попытки, повтор без дублей, чужой id, рейтинг и табло (только псевдонимы), отчёт и разбор для учителя, чужой учитель ничего не видит.

## Сквозной тест (`tests/e2e/flow.py`)

1. База `e2e`: шаги выше, но с одним пользователем `teacher@x`.
2. `DB=e2e node tests/mock-supabase.mjs` — мини-эмулятор Supabase на `:8787`. Пароль любого пользователя — `secret123`. Печатает тестовый `ANON`-ключ.
3. Собрать сайт на эмулятор: `PUBLIC_SUPABASE_URL=http://localhost:8787 PUBLIC_SUPABASE_ANON_KEY=<ANON> npm run build`, затем раздать `dist` как `/unmuzaj/` на `:4322`.
4. `python3 tests/e2e/flow.py` (нужен Playwright для Python).

Сценарий:
1. Учитель создаёт класс и получает ПИН.
2. Ученик занимается как гость, затем входит в класс; прогресс гостя переносится.
3. Ученик занимается карточками, проходит тест, теряет связь и восстанавливает её.
4. На втором устройстве виден тот же прогресс.
5. Срабатывает блокировка ПИН.
6. Рейтинг класса, страница «Мой прогресс», отчёт учителя, настоящие имена (видны только локально).

## Викторины (этап 4)

- `node tests/load_quiz.mjs` (нужен `ANON=<ключ>` из вывода эмулятора) — нагрузочный тест: 19 учеников одновременно отправляют результат, затем повторно. Ожидается 19 попыток, 380 ответов, без дублей.
- `python3 tests/e2e/quiz.py` — сквозной тест на телефоне 360 px: гость проходит викторину без сохранения; ученик проходит урок 10, связь пропадает и возвращается, результат сохраняется один раз; разбор ответов; «Мой прогресс»; аудирование в экзамене; табло проектора; вкладка «Викторины» у учителя, разбор и CSV. Если Playwright не находит браузер: `CHROMIUM=/путь/к/chrome python3 tests/e2e/quiz.py`.
- Пакеты для эмулятора (`pg`, `jsonwebtoken`) и проверки контраста (`axe-core`) — в devDependencies, ставятся `npm ci`.

## Оформление (дизайн 2.0, §14)

- `node tests/contrast.mjs src/styles/tokens.css` — быстрая проверка: все пары цветов (текст/фон) в 4 палитрах × 2 режимах проходят AA. Запускать после любой правки `tokens.css`.
- `python3 tests/e2e/design.py` — каждая страница × 4 палитры × 2 режима × ширина 360 и 1280: контраст AA через axe-core, нет горизонтальной прокрутки, нет ошибок в консоли; плюс окна «Оформление» и «Поиск», вопрос викторины, тест карточек; тема до отрисовки, «как в системе», сохранение выбора; размер текста; поиск (/, Ctrl+K, русский и арабский с огласовками и без); меню и «хлебные крошки». Скриншоты — в `test-results/design/`. `--quick` — 5 страниц вместо 21.
- Сайт для этого теста: `npm run build` (с поиском Pagefind) и раздать `dist` как `/unmuzaj/` на `:4322` (база не нужна).

## Языки интерфейса (§15.1)

- `npm run test:i18n` (`tests/i18n.mjs`) — быстрая проверка без сборки: в `uz.ts` и `en.ts` те же ключи, что в `ru.ts`; в каждой строке те же подстановки `{x}` и HTML-теги; узбекская орфография (oʻ, gʻ — знак ʻ U+02BB, тутуқ — ʼ U+02BC, без `'` ‘ ’ и кириллицы); `docs/uz_tekshirish.md` не устарел (иначе `npm run uz-review`).
- `python3 tests/e2e/i18n.py` — все страницы на `/uz/` и `/en/` при ширине 360 и 1280: `<html lang>`, hreflang на три версии и x-default; видимый русский текст есть только в непереведённых материалах (`lang="ru"`, с пометкой «(rus tilida)»); ссылки ведут на тот же язык; нет горизонтальной прокрутки и ошибок в консоли. Плюс переключатель в шапке и подвале, запоминание выбора (русская ссылка открывается на выбранном языке, `?параметры` сохраняются), карточки и викторина на узбекском, поиск на `/uz/`, страница 404 на языке адреса, русская версия без пометок. База не нужна. Сайт — как для `design.py`.
