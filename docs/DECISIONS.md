# Allimni — решения заказчика и открытые вопросы

> Обновлено 2026-10-18. Здесь только то, что **решил заказчик** (Отабек Икромбеков), и вопросы, на которые ответа ещё нет.
> Claude Code **не пересматривает решения из раздела 1 самовольно**. Чтобы изменить решение, заказчик пишет новое указание, и оно записывается сюда с датой.
> Источник каждой записи указан в скобках. «Сообщение заказчика» — текст в сеансе Claude Code; «ТЗ» — `docs/PRODUCT_SPEC.md`.

## 1. Действующие решения

### Безопасность и вход
| № | Решение | Дата | Источник |
|---|---|---|---|
| D1 | ПИН остаётся **4-значным**. Шестизначный ПИН и новая (растущая, по ученику) блокировка **не делать**: ни задач, ни кода. Текущая блокировка (5 ошибок / 10 мин на код, 60 на класс) не меняется | 2026-10-17 | сообщение заказчика; `docs/AUDIT_2026-10.md` 11.3 |
| D2 | 2FA включена на аккаунтах **GitHub, Supabase и Cloudflare** (заказчик видит три записи в приложении-аутентификаторе). Claude проверить это не может. На самом сайте TOTP не реализован | 2026-10-17 | сообщение заказчика |
| D3 | Вручную заказчиком: старое развёртывание Google Apps Script архивировано; регистрация новых пользователей в Supabase отключена; на GitHub включены Dependabot alerts, Secret Protection, push protection | 2026-10-17 | сообщение заказчика |
| D4 | В базе — **только псевдонимы**; настоящие имена ученика хранятся у преподавателя в браузере. Списки имён нигде публично не показываются | ТЗ §8 | ТЗ |
| D5 | Ключи `localStorage` с префиксом `unmuzaj:` **оставлены намеренно** (иначе пропали бы сохранённые данные) | 2026-10-14 | ТЗ §0.1 |
| D6 | Открытая регистрация по email выключена. Перед включением: включить «Allow new users to sign up» и подключить свой SMTP | 2026-10-17 | `docs/PROJECT_STATUS.md` |

### Что нельзя трогать без отдельного решения
| № | Решение | Дата | Источник |
|---|---|---|---|
| D7 | Старые страницы `public/v1/viktorina_*` и сам `public/v1/` **не удалять, не перемещать, не перенаправлять**. Упражнения всё ещё открывают страницы из `public/v1/` до переноса упражнений. Удаление и редиректы — только по отдельному решению | 2026-10-17, подтверждено 2026-10-18 | сообщение заказчика; AUDIT 11.4 |

| D9 | Действующие редиректы и индексируемые адреса не менять. Любой изменённый адрес — 301 + sitemap + canonical, без цепочек (правило 3) | 2026-10-15 | «Правила Allimni 2.0» |
| D10 | **Пробные экзамены** (`/mock/`, `/mock/tanal/nahw/`): не менять тексты и `id` вопросов; не менять движок обычных викторин ради экзамена; экзамен **не входит** в курс `tsu-2-sem1` (`courses: []`); режим концентрации — это сдерживание и учёт, а не защита от списывания; автора книги не выдумывать (в данных его нет); других экзаменов не создавать | 2026-10-18 | сообщение заказчика; проверено по коду (`docs/PROJECT_STATUS.md`) |
| D11 | Правила Allimni 2.0 (10 правил) в `CLAUDE.md` — дословно, без смысловых изменений | 2026-10-18 | сообщение заказчика |

### Как мы работаем
| № | Решение | Дата | Источник |
|---|---|---|---|
| D12 | **Предложения из аудита не реализуются автоматически.** Сначала Claude объясняет цель, пользу, риски, объём и способ проверки; затем ждёт согласия | 2026-10-17 | сообщение заказчика |
| D13 | **PR не сливается без явной команды заказчика «сливать».** Зелёный CI — условие, а не разрешение | 2026-10-17 | сообщение заказчика |
| D14 | SQL-миграции запускает только заказчик (или Claude по его отдельному явному разрешению) и только после просмотра. Рабочий Supabase без явного разрешения не трогаем | 2026-10-17 | сообщение заказчика |
| D15 | Сначала диагностика и единый план; **не начинать редизайн (E2), новые функции и крупные рефакторинги** до отдельного решения о переходе к реализации | 2026-10-18 | сообщение заказчика |
| D16 | Исправления из аудита — **по одной ограниченной группе** за раз, с согласованием | 2026-10-18 | сообщение заказчика |
| D17 | Перед каждой новой задачей Claude читает `CLAUDE.md` и `docs/PROJECT_*.md`, а после завершения обновляет статус и план. Один конкурирующий план — `docs/PROJECT_ROADMAP.md` | 2026-10-18 | сообщение заказчика |
| D18 | Для сокращения `CLAUDE.md` выбран режим Sonnet 5.5, средний effort. Выставленный effort Claude проверить не может | 2026-10-18 | сообщение заказчика |

## 2. Отклонено или отложено заказчиком
- **Отклонено:** ПИН из 6 цифр и связанные механизмы блокировки (D1).
- **Отложено:** удаление `public/v1/` и редиректы (D7); слияние ветки обратной связи (D8).
- **Отклонённое требование** «закрывать экзамен для пользователей без входа или по коду класса» — со слов заказчика; **в репозитории такого решения и кода нет** (экзамен доступен гостям, результат гостя хранится только на устройстве). Не возвращать без нового решения.

## 3. Предложения, ещё не одобренные
Из `docs/AUDIT_2026-10.md` и аудита 2026-10-18 (`docs/PROJECT_STATUS.md`, раздел «Аудит кода 2026-10-18»). Ни одно не является задачей, пока заказчик не согласует:
- убрать PT Serif или уменьшить шрифты первого экрана (AUDIT, раздел 5);
- грузить supabase-js только после входа (AUDIT, раздел 5);
- запускать SQL-тесты в CI (добавить Postgres-контейнер);
- не выкладывать сайт, пока не пройдены проверки (`deploy.yml`);
- чистить `login_fails` и просроченные `pin_tokens`;
- лимиты объёма данных на ученика (`sync_progress`);
- единая функция `esc()` вместо шести копий;
- обновления зависимостей (минорные: astro 7.4.0, supabase-js 2.118.0 и др.).
