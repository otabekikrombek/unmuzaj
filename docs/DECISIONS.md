# Allimni — решения заказчика и открытые вопросы

> Обновлено 2026-10-20. Здесь только то, что **решил заказчик** (Отабек Икромбеков), и вопросы, на которые ответа ещё нет.
> Claude Code **не пересматривает решения из раздела 1 самовольно**. Чтобы изменить решение, заказчик пишет новое указание, и оно записывается сюда с датой.
> Источник каждой записи указан в скобках. «Сообщение заказчика» — текст в сеансе Claude Code; «ТЗ» — `docs/PRODUCT_SPEC.md`.

## 2. Отклонено или отложено заказчиком
- **Отклонено:** ПИН из 6 цифр и связанные механизмы блокировки (D1).
- **Отложено:** удаление `public/v1/` и редиректы (D7); слияние ветки обратной связи (D8).
- **Отклонённое требование** «закрывать экзамен для пользователей без входа или по коду класса» — со слов заказчика; **в репозитории такого решения и кода нет** (экзамен доступен гостям, результат гостя хранится только на устройстве). Не возвращать без нового решения.

## 3. Предложения, ещё не одобренные

- убрать PT Serif или уменьшить шрифты первого экрана (AUDIT, раздел 5);
- грузить supabase-js только после входа (AUDIT, раздел 5);
- ✅ **выполнено 2026-10-19 (PR №18):** запускать SQL-тесты в CI (Postgres-контейнер);
- ✅ **выполнено 2026-10-19 (PR №19):** не выкладывать сайт, пока не пройдены проверки (`deploy.yml`);
- чистить `login_fails` и просроченные `pin_tokens`;
- лимиты объёма данных на ученика (`sync_progress`);
- единая функция `esc()` вместо семи копий (`git grep` по `origin/main`, `src`, 2026-10-19);
- обновления зависимостей (минорные: astro 7.4.0, supabase-js 2.118.0 и др.).
