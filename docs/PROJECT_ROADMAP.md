## 8. Модель и effort (решения D19, D22)
**Перед каждой задачей** Claude Code кратко оценивает сложность (низкая, средняя, высокая) и риски, рекомендует модель и уровень усилия и **ждёт подтверждения заказчика**; модель переключает заказчик (D22). Усилие — необходимое для задачи: не меньше, чем требуют сложность и риск, и без лишнего; на правильности не экономить (D20, п. 1).

| Задача | Рекомендация по умолчанию (уточняется оценкой сложности и риска) |
|---|---|
| Правки, реализация этапа, документы | Sonnet, средний |
| Проверка SQL-миграций и прав в базе | Opus |
| Крупные архитектурные решения | Opus |
| Sonnet дважды не справился с задачей | Opus |
| Проверка PR | чат-советник Claude, по реальному diff |

Максимальный effort по умолчанию не выбирать. Выставленную модель и effort Claude Code в сеансе проверить не может — не утверждать, что они применены.
