**Как читать статус:** *готово* — подтверждено кодом/Git/тестами; *частично* — часть есть, часть нет; *ожидает решения*; *запланировано*; *отложено*; *требует уточнения* — данных нет, указан источник, который нужно найти.

## 8. Модель и effort (рекомендации)
| Задача | Модель / effort |
|---|---|
| Небольшие правки текста, JSON, простые исправления | Sonnet, низкий |
| Обычная реализация этапа | Sonnet, средний |
| Сложная архитектура, безопасность базы, миграции | Opus, средний или высокий |
| Обсуждение плана, обучение, проверка PR | обычный чат, модель по сложности |
| Независимая проверка SQL (PR, затрагивающие базу) | отдельно, свежая сессия |

Не выбирать максимальный effort по умолчанию. Выставленный effort Claude Code в сеансе проверить не может — не утверждать, что он применён.

## 9. Когда этап завершён и можно идти дальше
1. Согласованные критерии приёмки выполнены, проверки пройдены (CI зелёный; SQL-тесты и нужные e2e — локально).
2. Для базы: миграция применена вручную заказчиком, результат проверен.
3. После слияния — ручная проверка с телефона по списку, согласованному для этапа.
4. `PROJECT_STATUS.md`, этот план и `DECISIONS.md` обновлены.
5. Заказчик подтвердил переход к следующему этапу. Новых «широких» аудитов без причины не проводить.
