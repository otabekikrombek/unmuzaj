# Как работать над сайтом в Claude Code

Claude Code в браузере — это чат, который работает прямо с репозиторием `unmuzaj` на GitHub: пишет код, запускает тесты и отправляет изменения на GitHub.

## 1. Начать сеанс
1. Откройте **https://claude.ai/code** (или вкладку **Code** в приложении Claude на телефоне).
2. Под полем ввода — выбор репозитория. Выберите **otabekikrombek/unmuzaj**, ветку оставьте **main**.
3. Рядом — режим работы:
   - **Plan** — Claude сначала пишет план и ждёт вашего «да». Для больших задач (новый раздел, викторины).
   - **Accept edits** или **Auto** — сразу делает. Для мелких правок («поменяй текст на главной»).
4. Напишите задачу и нажмите Enter. Можно закрыть вкладку: сеанс продолжит работать, результат будет ждать.

## 2. Как писать задачи
- **Одна задача — один сеанс.** Новый раздел или этап — новый сеанс: так быстрее и дешевле, чем один бесконечный чат.
- Первая строка всегда: «Прочитай CLAUDE.md (особенно разделы 12 и 13).»
- Пишите, **что** должно получиться, а не как: «На главной под словом дня — поле "Спряжение глагола"; ввёл глагол → открылась таблица».
- Прикладывайте снимки экрана ошибок и пишите, на каком устройстве это было (телефон, компьютер).
- В конце просите: «Обнови раздел 12 CLAUDE.md и дай список, что проверить с телефона».

## 3. Как изменения попадают на сайт
1. Закончив, Claude отправляет изменения на GitHub **в отдельную ветку** (название вида `claude/...`) — сайт пока не меняется.
2. В сеансе появится счётчик изменений (например `+120 −15`). Нажмите на него — увидите изменения. Можно оставить замечание к строке.
3. Нажмите **Create PR** (запрос на слияние).
4. Откройте этот PR на GitHub → кнопка **Merge pull request** → **Confirm merge**.
5. Через 1–2 минуты сайт обновится сам (вкладка **Actions** на GitHub: зелёная галочка — опубликовано, красный крестик — ошибка, пришлите её снимок Claude).

Можно попросить Claude в сеансе: «создай PR и смёрджи его в main» — если у него есть такие права, он сделает это сам.

## 4. Когда меняется база данных
Если Claude добавил файл `supabase/migrations/000N_….sql`, его нужно выполнить один раз:
Supabase → **SQL Editor** → **New query** → вставить текст файла → **Run** (на предупреждение — «Run and enable RLS»).
Порядок: сначала SQL, потом Merge PR.

## 5. Новые материалы (слова, викторины, статьи, книги, видео)
- Материалы готовятся в обычном чате Claude (проект «Arabic language for 2 course»), там есть веб-поиск. Просите: «дай JSON для сайта Unmuzaj по формату из src/content/SCHEMA.md».
- Добавить: GitHub → папка `src/content/<тип>/` → **Add file → Upload files** → загрузить JSON → **Commit changes**. Сайт обновится сам.
- Или отдайте JSON в сеанс Claude Code: «добавь этот набор слов».

## 6. Правила безопасности
- Claude можно давать: адрес Supabase и **anon**-ключ (они уже в коде).
- **Никогда** не давать: пароль базы, ключ `service_role` / `Secret key`, пароль учителя.

## 7. Если что-то сломалось
- Сайт не открывается или старый → GitHub → **Actions** → последняя строка. Красная — пришлите снимок Claude.
- «Нет связи с сервером» у всех → Supabase могла уснуть: supabase.com → проект → **Restore**.
- Вернуть как было → в Claude Code: «откати последний PR».
